## About the project

**Task Management API** is a study project for the course "Professional-oriented practicum in a foreign language".
It shows how to describe a REST API with OpenAPI 3.0, generate an SDK client and publish interactive documentation with Zudoku.

- **Domain:** Task management system (entities: Task, Project)
- **Specification:** OpenAPI 3.0.3, see the [API Reference](/api)
- **SDK:** TypeScript, generated from the same spec
- **Author:** Taras Artiukh, Zaporizhzhia National University, Faculty of Mathematics, Department of Computer Science
